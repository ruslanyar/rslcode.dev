# rslcode.dev - Personal Portfolio & Blog

This is the source code for my personal website, blog, and portfolio, built with Next.js and TypeScript.

## ✨ Features

- **MDX Blog:** Articles are written in MDX, allowing for interactive React components directly within posts.
- **Syntax Highlighting:** Code blocks are beautifully highlighted using `rehype-expressive-code`.
- **Bilingual (i18n):** Full support for English and Russian, powered by Next.js App Router internationalization.
- **Responsive Design:** Styled with Tailwind CSS for a clean and responsive layout.
- **Automated Code Quality:** Pre-commit hooks with Husky and lint-staged enforce linting and formatting.

## 🛠️ Tech Stack

- **Framework:** [Next.js](https://nextjs.org/) (App Router)
- **Language:** [TypeScript](https://www.typescriptlang.org/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Content:** [MDX](https://mdxjs.com/)
- **Syntax Highlighting:** [Expressive Code](https://expressive-code.com/)
- **Linting/Formatting:** [ESLint](https://eslint.org/), [Prettier](https://prettier.io/)

## 🚀 Getting Started

1. **Clone the repository:**

   ```bash
   git clone https://github.com/ruslanyar/rslcode.dev.git
   cd rslcode.dev
   ```

2. **Install dependencies:**

   ```bash
   npm install
   ```

3. **Run the development server:**

   ```bash
   npm run dev
   ```

Open [http://localhost:3000](http://localhost:3000) in your browser to see the result.

# rslcode.dev — Персональное портфолио и блог

Это исходный код моего личного сайта, блога и портфолио, созданного с помощью Next.js и TypeScript.

## ✨ Возможности

- **Блог на MDX:** Статьи написаны в формате MDX, что позволяет вставлять интерактивные React-компоненты прямо в посты.
- **Подсветка синтаксиса:** Блоки кода красиво подсвечиваются с помощью `rehype-expressive-code`.
- **Два языка (i18n):** Полная поддержка английского и русского языков с использованием встроенной в Next.js App Router интернационализации.
- **Адаптивный дизайн:** Стилизация с помощью Tailwind CSS для чистого и адаптивного макета.
- **Автоматизация качества кода:** Pre-commit хуки с Husky и lint-staged для автоматического линтинга и форматирования.

## 🛠️ Стек технологий

- **Фреймворк:** [Next.js](https://nextjs.org/) (App Router)
- **Язык:** [TypeScript](https://www.typescriptlang.org/)
- **Стили:** [Tailwind CSS](https://tailwindcss.com/)
- **Контент:** [MDX](https://mdxjs.com/)
- **Подсветка синтаксиса:** [Expressive Code](https://expressive-code.com/)
- **Линтинг/Форматирование:** [ESLint](https://eslint.org/), [Prettier](https://prettier.io/)

## 🚀 Локальный запуск

1. **Клонируйте репозиторий:**

   ```bash
   git clone https://github.com/ruslanyar/rslcode.dev.git
   cd rslcode.dev
   ```

2. **Установите зависимости:**

   ```bash
   npm install
   ```

3. **Запустите сервер для разработки:**

   ```bash
   npm run dev
   ```

Откройте [http://localhost:3000](http://localhost:3000) в вашем браузере.
